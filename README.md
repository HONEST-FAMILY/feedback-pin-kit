# 어니스트 피드백 핀 (HFFeedback)

만들어 준 사이트 화면 위에 고객이 피그마 댓글처럼 바로 피드백을 남기는 부품입니다. 어니스트패밀리 자체 코드이고 외부 라이브러리는 쓰지 않습니다.

- 피드백은 AI 대시보드(api.dashboard.honest-family.com)에 저장되고, 대시보드 **고객 피드백** 메뉴에서 보고 완료 처리합니다.
- 고객 화면: 오른쪽 위 '피드백 남기기' 단추를 켜면 피드백 모드. PC는 **우클릭**, 폰은 **꾹 누르기**로 그 자리에 핀을 남깁니다. 일반 클릭·탭은 평소처럼 동작해 메뉴를 열거나 버튼을 눌러 본 상태에서도 남길 수 있습니다.
- 마우스를 올리면 그 요소에 반투명 상자와 이름(버튼·링크·제목·사진 등)이 떠서 어디에 남는지 보입니다.
- 남길 때 기기(PC·휴대폰·태블릿), 운영체제, 브라우저(크롬·사파리·삼성 인터넷·엣지·웨일·카카오톡/네이버/인스타그램 앱 안 브라우저 등), 화면 크기·보던 화면(모바일/PC)이 자동으로 함께 저장됩니다.
- 팀이 완료로 표시하면 핀이 초록색이 되고 '완료 코멘트'(무엇을 고쳤는지 한 줄)가 함께 보입니다. 고객이 목록의 '완료 · 확인해 주세요'에서 누르면 그 자리로 이동해 강조해 보여 줍니다. 고객은 '확인했어요' 또는 '아직 안 됐어요'를 누를 수 있습니다.
- 우리 팀용 링크(`사이트주소/#hffb=on&hffbt=팀 키`, 대시보드 고객 피드백에서 복사)를 한 번 연 기기에서는 사이트 화면의 핀을 눌러 바로 '완료 처리'(완료 코멘트 필수)·'코멘트 고치기'·'다시 열기'·'지우기'를 합니다. 고객에게는 보내지 않습니다. 새는 일이 생기면 대시보드에서 '팀 링크 새로 만들기'로 예전 링크를 막습니다.
- 고객은 자기 기기에서 남긴 피드백을 팀이 고치기 전('남은 것')까지 핀을 눌러 '지우기'로 지울 수 있습니다.

## 붙이는 법

AI 대시보드에서 그 프로젝트로 이슈를 만들고 라이브러리 **고객사 피드백 시스템 도입**을 고르면, 워커가 사이트 연결부터 붙이기·검수까지 처리합니다.

직접 할 때는 대시보드 > 고객 피드백 > '+ 사이트 연결'에서 사이트를 만들면 나오는 한 줄을, 모든 화면이 함께 쓰는 레이아웃의 `</body>` 바로 위에 넣습니다.

```html
<script src="https://honest-family.github.io/feedback-pin-kit/hf-feedback.js" data-key="fb_xxxxxxxx" data-invite defer></script>
```

| 속성 | 설명 |
|---|---|
| `data-key` | 사이트 키 (필수) |
| `data-invite` | 초대 링크(`사이트주소/#hffb=on`)를 한 번 연 기기에서만 단추를 보여 준다. 일반 방문자에게는 안 보인다. 그 기기에서 끄려면 `#hffb=off`. 공개 전 시안에서만 뺀다 |
| `data-top` | 오른쪽 위 단추의 위쪽 여백(px). 사이트 머리줄과 겹치면 늘린다 |
| `data-hide` | 피드백 모드에서 숨길 요소 선택자(예: 사이트 전용 마우스 커서 `#cursor`) |
| `data-api` | 저장 주소를 바꿀 때만 |

- 피드백 모드는 오른쪽 위 단추로 켜고 끕니다(PC는 Esc로도 꺼짐). 켠 채로 다른 화면으로 넘어가면 10분 안에는 이어지고, 그보다 오래 지나 다시 열면 꺼진 채로 시작합니다.
- 사이트 주소가 대시보드에 등록되지 않았거나(403) 사이트 연결이 해제되면(404) 단추가 스스로 사라지고, 개발자 도구 콘솔에 `[hf-feedback]` 안내가 한 줄 남습니다.
- 사이트에 보안 정책(Content-Security-Policy)이 있으면 `script-src`에 `https://honest-family.github.io`, `connect-src`에 `https://api.dashboard.honest-family.com`을 더합니다.

## 한계

- 화면에 보이는 요소에 남깁니다. 내부 동작 문제(예: 등록이 안 됨)는 그 버튼에 남기면 됩니다.
- 화면 구조가 크게 바뀌면 옛 핀은 남긴 자리 근처(문서 위치)로 대신 보입니다.
